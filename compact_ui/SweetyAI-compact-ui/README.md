# SweetyAI compact UI

This package keeps the user's supplied compact Sweety/Coucou-style layout and connects the chat to the existing SweetyAI API at:

`http://127.0.0.1:8765/chat`

Replace only:
- `C:\SweetyAI\src\main.ts`
- `C:\SweetyAI\src\styles.css`

The existing `package.json`, Tauri configuration, and Python backend are intentionally untouched.
